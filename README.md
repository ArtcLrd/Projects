# DoIt - Advanced Todo Management Application

## 🚀 Project Overview

DoIt is a feature-rich, responsive Todo management application built with React.js and Vite, designed to help users organize and track their tasks efficiently across multiple devices.

![Project Banner](path/to/your/project-banner.png)

## ✨ Features

- 📝 Create, Edit, and Delete Tasks
- ⭐ Mark Tasks as Favorite
- ✅ Task Completion Tracking
- 📅 Set Due Dates and Reminders
- 🌓 Dark/Light Mode Support
- 📱 Fully Responsive Design
- 🔒 Secure User Authentication
- 💾 Local Storage Persistence

## 🛠 Tech Stack

- **Frontend**: React.js
- **Build Tool**: Vite
- **State Management**: Redux
- **Styling**: Bootstrap
- **Icons**: React Icons
- **Authentication**: Redux-based Session Management

## 🌟 Key Functionalities

### Task Management
- Create tasks with detailed information
- Set priority and favorite status
- Add due dates and reminders
- Mark tasks as complete/incomplete

### User Experience
- Responsive design for all device sizes
- Dark and light mode toggle
- Intuitive and clean user interface
- Local storage for data persistence

### Authentication
- Secure user sessions
- Login/Logout functionality
- Protected routes

📱 Responsive Design
The application is built with a mobile-first approach using Bootstrap, ensuring a seamless experience across:

  Mobile Phones
  Tablets
  Desktop Computers
